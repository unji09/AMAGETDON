## 2. 프로젝트에서 사용하는 외부 서비스 정보

### 카카오 (소셜 로그인)
| 항목 | 내용 |
|------|------|
| 서비스 | Kakao Developers |
| 용도 | 카카오 OAuth 소셜 로그인 |
| 가입 URL | https://developers.kakao.com |
| 필요 키 | REST API Key (`REST_KAKAO_API_KEY`), JavaScript Key (`VITE_KAKAO_JS_KEY`) |
| 설정 | 리다이렉트 URI 등록 필요 (`REDIRECT_URL`) |

### 한국투자증권 (주식 데이터)
| 항목 | 내용 |
|------|------|
| 서비스 | 한국투자증권 Open API |
| 용도 | 실시간 주식 시세, 캔들차트 데이터 수집 |
| 가입 URL | https://apiportal.koreainvestment.com |
| 필요 키 | API Key/Secret 2세트 (`STOCK_API_KEY/SECRET`, `CANDLE_API_KEY/SECRET`), HTS ID (`KIS_HTS_ID`) |

### Gmail SMTP (이메일)
| 항목 | 내용 |
|------|------|
| 서비스 | Google Gmail SMTP |
| 용도 | 이메일 인증 발송 |
| 설정 | Gmail 계정에서 앱 비밀번호 발급 필요 |
| 필요 키 | 앱 비밀번호 (`MY_EMAIL_PASSWORD`) |
| SMTP 설정 | Host: `smtp.gmail.com`, Port: `587` |

### OpenVidu (WebRTC)
| 항목 | 내용 |
|------|------|
| 서비스 | OpenVidu CE (자체 호스팅) |
| 용도 | 실시간 채팅 (WebSocket 시그널링) |
| 설치 | EC2에 `/opt/openvidu/`에 직접 설치 |
| 공식 문서 | https://docs.openvidu.io/en/2.30.0 |

### Let's Encrypt (SSL 인증서)
| 항목 | 내용 |
|------|------|
| 서비스 | Let's Encrypt |
| 용도 | HTTPS SSL/TLS 인증서 무료 발급 |
| 도구 | certbot 2.9.0 |
| 갱신 | 90일마다 자동/수동 갱신 필요 |

### SSAFY GMS (퀴즈 생성)
| 항목 | 내용 |
|------|------|
| 서비스 | SSAFY GMS API |
| 용도 | AI 퀴즈 생성 (FastAPI에서 호출) |
| 필요 키 | `GMS_API_KEY` |

## 3) 배포 시 특이사항

### 브랜치 변경 필수
- **배포 브랜치**: `feat/S14P11A207-237-infra-fix`
- **기본 브랜치**: `master`
- 배포 시 반드시 `feat/S14P11A207-237-infra-fix` 브랜치로 체크아웃 후 빌드해야 함
  ```bash
  git checkout feat/S14P11A207-237-infra-fix
  git pull origin feat/S14P11A207-237-infra-fix
  ```

### Docker 네트워크
- 모든 서비스가 `network_mode: host` 사용
- 컨테이너 간 통신은 `localhost`로 처리 (Docker 브릿지 네트워크 미사용)

### DB 초기화
- 최초 실행 시 `01-schema.sql`, `02-load-data.sql`이 자동 실행
- CSV 데이터: chapters, quizzes, quiz_choices, survey_questions, achievements

### AWS 보안그룹 필요 포트
| 포트 | 프로토콜 | 용도 |
|------|----------|------|
| 80 | TCP | HTTP → HTTPS 리다이렉트 |
| 443 | TCP | HTTPS (메인 서비스) |
| 3478 | UDP | STUN/TURN (WebRTC) |
| 8000-8999 | TCP | OpenVidu WebSocket (8443) |


### SSL 인증서
- Let's Encrypt 인증서 사용 (경로: `/etc/letsencrypt/live/i14a207.p.ssafy.io/`)
- 인증서 도메인: `i14a207.p.ssafy.io`, `www.amagetdon.site`
- nginx 컨테이너에서 `/etc/letsencrypt`를 읽기 전용으로 마운트
- 인증서가 없을 경우 자동으로 self-signed 인증서 생성 (로컬 개발용)

### OpenVidu 설정
- OpenVidu CE 2.32.1이 `/opt/openvidu/`에 별도 설치됨
- `HTTPS_PORT=8443`, `HTTP_PORT=8081`
- 인증서 타입: `owncert` (프로젝트 Let's Encrypt 인증서 공유)
- 인증서 복사 경로: `/opt/openvidu/owncert/certificate.cert`, `certificate.key`


### 배포 명령어
```bash
# 전체 빌드 및 배포
cd ~/S14P11A207 && docker compose up -d --build

# OpenVidu 재시작 (별도)
cd /opt/openvidu && sudo ./openvidu restart
```

## 4) DB 접속 정보 등 프로젝트에 활용되는 주요 계정 및 프로퍼티가 정의된 파일 목록

| 파일 경로 | 내용 |
|-----------|------|
| `.env` (프로젝트 루트) | 전체 환경변수 (DB, API키, JWT, 카카오, OpenVidu 등) |
| `AMAGETDON-BE/src/main/resources/application.yaml` | Spring Boot 메인 설정 (DB URL, Redis, JWT, Mail, OpenVidu, Swagger) |
| `docker-compose.yaml` | 서비스별 환경변수 주입 및 컨테이너 설정 |
| `nginx/nginx.conf` | 리버스 프록시 설정, SSL, 라우팅 규칙 |
| `/opt/openvidu/.env` (EC2) | OpenVidu 서버 설정 (도메인, 포트, 시크릿, 인증서 타입) |

### DB 접속 정보
| 항목 | 값 |
|------|-----|
| Host | `localhost` (컨테이너 내부) |
| Port | `3306` |
| Database | `amagetdon` |
| User | `root` |
| Password | `.env`의 `DB_PASSWORD` |
| Character Set | `utf8mb4` |
| Collation | `utf8mb4_unicode_ci` |
